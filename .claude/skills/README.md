# Claude Code skills

The UI and animation skills in this folder are copied unchanged from
[emilkowalski/skills](https://github.com/emilkowalski/skills) at commit
`64eb3deb9a5fbfa041faf783e0bc3fd635872e9c` (15 Nov 2026), under the MIT licence in
`LICENSE-emilkowalski-skills`.

Five upstream skills are left out because they don't fit a static vanilla-JS site: `animate-expo`
(React Native), `write-swift` (Swift), `ask-sonner` (a React toast library), `gestures` (drag and
swipe UI) and `prototype` (multi-version prototypes). `ask-emil` and a few others still mention
them by name; they aren't installed here, so skip those suggestions.

To update them, copy the `skills/` folder from a newer commit of that repo over this one, delete the
five skills above again, and change the commit above.

They are guidance for Claude Code sessions only: nothing here is built, tested or published on the site.
The project rules in `CLAUDE.md` still win (keep the existing design, UK spelling, test at 390px and 1280px).
